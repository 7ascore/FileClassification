Минискрипт для сортировки файлов в папке.
study_model хранит в себе веса модели(тут она обучена классифицировать pdf-ки на матан, алгебру и геометрию/топологию)
в принципе универсально, достаточно файлу DataCollection скормить размеченные данные(пдфки, соответствующие определенному классу в папку с соответствующим именем) и подправить пути файловой системы.
